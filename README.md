# Claude plugins by Parker Lyons

| Plugin | What it does |
|---|---|
| [PMM Framework](pmm-framework/) | A Product Marketing Director agent: guided setup and PMM health check, then research, strategy, positioning, launches, and post-launch growth. |
| [ADHD Coach](adhd-coach/) | A pocket ADHD coach: builds a private "manual of me" during a short onboarding, then helps you decide what's next, plan around your energy, and get unstuck. |
| [PM Interview Coach](pm-interview-coach/) | An adaptive interview coach: prep briefs, transcript scoring on five dimensions, a storybank, mocks, debriefs and negotiation, with progress that carries across chats. |

See each plugin's README for install and getting-started instructions.
