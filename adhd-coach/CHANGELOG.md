# Changelog

All notable changes to the ADHD Coach plugin. Versions follow [semantic versioning](https://semver.org): minor versions add or expand skills; patch versions fix wording or errors.

## [0.1.0] — 2026-11-02

First release: onboarding and the Manual of Me.

### Added
- **`onboarding` skill**: an ADHD-friendly intake with three paths (fast start, full setup, free-form brain dump), six optional modules, a "here's what I heard" playback after each, import of existing intake forms and assessment results, a connection check (calendar, tasks including Apple Reminders and paper lists, email, files), agreement on one master task list, proactive check-ins created as scheduled tasks (with one-minute standup and retro templates, a travel mode and guilt-free restarts), an optional wheel of life, a blind quarterly refresh, and a closing next step.
- **`references/manual-of-me-template.md`**: the private profile every skill reads, covering priorities, ADHD challenges, what has worked, tools, energy and rest, processing modalities, strengths, values, motivation, self-compassion, the long view, coaching preferences and check-ins, plus experiment and wins logs.
- **`references/question-bank.md`**: the questions for each module, how to interpret Self-Compassion Test scores, and rules for importing existing material.
- **`references/coaching-principles.md`**: persona, design principles, tone, and boundaries (coach, not clinician; distress and crisis handling; consent before any action; privacy) shared by all skills.
- **`references/saving-the-manual.md`**: storing the manual privately in a Claude Project, Google Drive, or a folder on the user's computer.
