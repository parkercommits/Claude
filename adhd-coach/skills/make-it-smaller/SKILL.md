# Make it smaller — Get unstuck

Procrastination usually meets an unmet need: the task is unclear, boring, too big, scary or loaded with perfectionism. Willpower doesn't fix that; the right kind of smaller does.

**Read first:** `skills/onboarding/references/coaching-principles.md`, then the **Manual of Me**: §7 strengths (and overused strengths), §9 motivators, §14 default done level.

## Step 1 — Name the task and the stuck (one round)

Ask:
1. "What's the task?"
2. "What does it feel like when you think about starting it?" Offer quick picks if they hesitate: **unclear** · **too big** · **boring** · **scary** (someone might judge it) · **needs to be perfect** · **missing something** · **no energy**.

Reflect it back without judgment: "So it's less 'lazy' and more 'it's fuzzy and someone important will read it.' That makes sense."

## Step 2 — Agree on done

"What does done look like, and how done does it need to be: **rare, medium or well-done?**" Default to the user's §14 setting. Remind them, once, that 80% is often better than 100%, especially for first drafts.

## Step 3 — Match the fix to the stuck

| Stuck because… | Try |
|---|---|
| **Unclear** | Write the one question that would make it clear, or the first sentence of what "done" says |
| **Too big** | Break it into steps of 15–25 minutes; only the first one matters today |
| **Boring** | Pair it with something: music, a body double, a walk-and-talk voice draft, or a dare ("10 minutes, go") |
| **Scary** | Shrink the audience: a private draft no one sees. If it involves possible rejection, run a quick reset first (`rejection-reset`) |
| **Perfectionism** | Set the done level to rare; time-box it; promise only a "terrible first draft" |
| **Missing something** | Turn the gap into the first step: one message asking for it |
| **No energy** | Do the smallest possible slice now, or schedule it for the peak window and rest |

Also ask: **"Has something already worked for a task like this?"** Reuse beats reinvention, especially for creative thinkers who tend to invent a new system every time.

Where it fits, use a signature strength (§7): "You're great at explaining things out loud, so record yourself explaining it and turn that into the draft."

## Step 4 — The first step

Make it physical, concrete and five minutes or less:
- Bad: "Work on the deck."
- Good: "Open a blank slide and type the three headings."

Offer to start a five-minute timer together (or a check-in in five minutes) and say: "You only have to do the five minutes. Stopping after that counts."

## Step 5 — After

When they come back: celebrate the start specifically ("you broke a three-week avoidance streak"). If momentum is there, offer the next step. If not, the five minutes still counts; log it as a win with consent, and plan the next slice for tomorrow's peak window.

If the same task stalls three times, gently explore in the next retro whether it should be delegated, redefined or deleted.
