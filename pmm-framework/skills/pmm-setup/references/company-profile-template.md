# Company profile — template

The company profile is the durable, team-wide context every PMM skill reads. It's one document by default — easy to upload to a Claude Project or share in Drive — with numbered sections. Larger teams can split sections into separate documents later; keep the numbering.

**How to fill it:**
- Draft from public research and the assets the user shared, then ask the user to correct the draft. Don't make them type what you can find.
- Summarize; don't paste whole source documents. Link or name the source instead (e.g., "Brand guidelines v3, uploaded to this project").
- Mark anything unconfirmed with ❓ and anything missing with "Not yet defined" — the health check and first moves will address it.
- Customer quotes: no names or identifying details unless the user says otherwise.
- Every section gets an **Owner** (a role is fine) and a **Last updated** date.
